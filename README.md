## accesibility test

### visuele beperking

Bij een blurry vision is het mogelijk om de titels te lezen, verder niet.

Bij slecht contrast is het lastig om het formulier op de index te lezen, verder is het geen probleem op de site.

De andere visuele beperkingen die je kunt testen via chrome leveren geen problemen op op een plek in de website.


### tabben

Als ik door de website heen probeer te tabben vallen me een aantal dingen op: er is geen speciaal tab menu, er zijn een aantal lange stukken aan links die je niet kunt overslaan (is opzich niet heel erg). Verder is de site netjes ingericht voor mensen zonder muis.


### reduced motion

Er is op de homepagina een deel van de site dat een lijst met klanten laat ronddraaien, als ik reduced motion aanzet blijft die bewegen, dat is iets wat ik uit zou zetten.


### screen reader

Het logo en de titel van de site zijn niet leesbaar voor de screen reader
